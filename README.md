# Cloud Native DevOps Web Service

## 🌐 Live Project
https://cloud-native-devops-service.onrender.com

## 📌 Features
- Flask-based REST API
- Docker containerization
- Cloud deployment using Render
- Health monitoring endpoint

## 🔗 Endpoints
/ - Home  
/health - Status  
/about - Info  

## ⚙️ Tech Stack
- Python (Flask)
- Docker
- GitHub
- Render

## 🚀 How to run locally
docker build -t devops-app .
docker run -p 5002:5001 devops-app
